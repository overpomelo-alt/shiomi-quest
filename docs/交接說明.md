## 1. 這是什麼

平等國小五年級（全班 5 人）的跨科闖關遊戲，在瀏覽器裡玩，手機、平板、電腦都可以。

- 學生用座號登入，在 3D 小鎮「汐見町」和學生住的村子「Sqoyaw」（環山部落）裡走動，到各個地點答題、拿印章、賺金幣，用來養寵物、轉扭蛋、布置自己的房間。
- 老師有老師模式，可以改題目、看進度、發公告、補發印章、設定天色。

**遊戲網址**
- 學生：https://overpomelo-alt.github.io/shiomi-quest/
- 老師：https://overpomelo-alt.github.io/shiomi-quest/?teacher

**原始碼**：https://github.com/overpomelo-alt/shiomi-quest（公開 repo）

## 2. 使用的技術

| 項目 | 內容 |
|---|---|
| 3D 引擎 | three.js r128，內嵌在 `dev/src/engine.js`，不從 CDN 載入，避免學校網路擋住 |
| 程式 | 純 JavaScript，沒有框架、沒有打包工具；主要程式全部在 `dev/src/game.js`（約 7,000 行） |
| 3D 模型 | **沒有外部模型檔（沒有 GLB、FBX）**。房子、樹、地形、車站都是 game.js 用程式產生的 |
| 2D 手繪場景 | 房間、校門口、操場是 ChatGPT 畫的整張圖，加上遮擋物圖層和可走區域資料（`room.json`），用 canvas 畫 |
| 角色 | 2D 紙娃娃角色：圖集 webp 加影格表，可以換臉、換裝 |
| 建置 | Python 3（Pillow、numpy），`dev/build.py` 把所有東西組成一個網頁 |
| 雲端 | Firebase：匿名登入加 Firestore，透過 REST API 存取，沒有用 Firebase SDK |
| 主機 | GitHub Pages，從 main 分支根目錄直接發布 |
| 離線 | Service Worker（`sw.js`），版本號不同時頁面會自動重新載入 |
| 測試 | Node 22 加 Playwright 無頭 Chromium（`dev/tests/`） |

套件版本請看 `dev/requirements.txt` 和 `dev/tests/package.json`。

## 4. 怎麼啟動、修改、部署

**只是要玩**：打開遊戲網址。

**在自己電腦上跑**：
```bash
cd dev
pip install -r requirements.txt
python3 build.py                  # 產生 dist/（本機版）和 web/（網路版）
cd dist && python3 -m http.server 8765
# 瀏覽器開 http://localhost:8765/
```
- `dist/index.html` 也可以直接雙擊打開，但這樣沒有雲端功能。
- `.webcache/` 在的話，build 大約 1 分鐘；沒有的話要重新壓縮全部圖片，大約 10 分鐘。

**部署**：
1. 把 `dev/web/` 裡的 `index.html`、`sw.js`、`version.json`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png` 複製到 repo 根目錄。
2. 讓根目錄的 `assets/` 和 `dev/web/assets/` 一樣：多的刪掉，但不要動 `assets/source/`。
3. commit、push 到 main。GitHub Pages 大約 1～3 分鐘會更新。

**注意事項**：
- 整個 repo 約 900 MB，GitHub Pages 網站上限是 1 GB。素材再增加就要把 `assets/source/` 搬到另一個 repo，或改成用 GitHub Actions 只發布遊戲檔案。
- 同一時間只能有一個人（或一個 Claude 工作階段）在改這個 repo，不然 push 會互相蓋掉。

## 5. Firebase

**專案**：`shiomi-quest`
- Web API key 寫在程式裡，`FB.key` 在 game.js，`KEY` 在 boot.js。
- 資料庫 id 是 `(default)`；如果不存在，程式會改試 `shiomi-quest-1a2b3`。

**登入方式**：
- 每台裝置用「匿名登入」（Identity Toolkit `accounts:signUp`）。
- refresh token 存在瀏覽器的 `localStorage['shiomi-fb']`。
- 所以 Firebase 後台必須開啟「匿名」登入方式。

**資料結構**：全部在 `shiomi` 這個集合底下。每份文件的內容都是一個 JSON 字串，放在欄位 `d`。

| 文件路徑 | 誰寫 | 內容 |
|---|---|---|
| `shiomi/config` | 老師 | 老師的全部設定：`d` 是 JSON（題目 `stations`、公告 `news`、倒數 `countdowns`、海玻璃單字 `words`、金幣設定、班級密碼 `classPass`、老師密碼雜湊 `tpass`、天色 `sky`、即時同步 `presence`／`presenceMin`、扭蛋價格 `gachaPrice`、`resets` 等）；`t` 是時間 |
| `shiomi/seat-<座號>` | 學生 | 學生存檔：`d` 是 JSON（`coins`、印章 `st`、物品 `items`、房間 `home`、寵物 `pet`、外觀 `look`、紀錄 `hist`、錯題 `wrong`、帳本 `ledger` 等）；另外有 `t`（最後存檔時間）、`seat`、`name` |
| `shiomi/gift-<座號>` | 老師 | 老師補發的印章和金幣，也用來放「重設進度」的標記：`d` 是清單 `[{id,t,st:[關卡 id],coins,note}]`，重設的項目是 `{reset:時間}` |
| `shiomi/msg-<座號>` | 同學 | 學生房門口留言板：`d` 是清單 `[{id,from,name,text,t}]` |
| `shiomi/pres/live/<座號>` | 學生 | 即時同步：上線時的位置、外觀、區域，離線時刪除 |
| `shiomi/_ping` | — | 連線測試 |

**讀寫頻率**：
- 學生存檔每 30 秒一次。
- 補發的禮物每 3 分鐘讀一次，留言每 5 分鐘讀一次，天色設定每 1 分鐘讀一次。
- 即時同步會一直讀寫，每台裝置每天有分鐘數上限，預設 40 分鐘，老師可以調。

**權限規則（Security Rules）**：
- **規則只存在 Firebase 後台，repo 裡沒有。** 我（Claude）看不到後台，所以無法附上目前實際用的版本。
- 請到 Firebase 後台 → Firestore Database →「規則」分頁，把內容複製下來存成 `docs/firestore.rules`。
- 遊戲需要的權限：
  - 已登入（匿名也算）的使用者，可以讀寫 `shiomi/` 底下所有文件，包括 `pres/live` 子集合。
  - 遊戲會列出整個 `shiomi` 集合，用在老師看全班進度、讀取重設標記，所以也需要「列出」的權限。
- 參考寫法（只限已登入使用者，不分角色）：
  ```
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /shiomi/{doc=**} {
        allow read, write: if request.auth != null;
      }
    }
  }
  ```
- 安全性提醒：
  - 老師模式和班級密碼只在遊戲畫面上檢查，資料庫本身沒有區分老師和學生。
  - 懂技術的人可以直接改別人的存檔或老師設定。
  - 如果之後要加強，需要改成真正的帳號登入，再依帳號寫規則。

## 6. 已完成

- **學習主線**：
  - 汐見町 14 個關卡：國語 5、英文、自然、社會、音樂、健康，以及挑戰館 4 關（數學、成語、科學、謎題）。
  - 答對拿印章和金幣；集章卡用 Google 表單交成績。
- **場景**：
  - 3D：汐見町小鎮、海岸、燈塔、神社、車站、Sqoyaw 村子。
  - 2D 手繪：學生房、老師小屋（含浴室、躺床）、便利商店、五年級教室、車站大廳、校門口、操場。
  - 探險：神秘小島、瀑布迷宮。
- **生活系統**：
  - 自己的房間可以布置家具；同學互訪時，門鎖由主人設定。
  - 留言板、扭蛋、換裝。
  - 寵物：貓、柴犬、老師的狗「蝴蝶」。
  - 動物之家：可以領養，也有保育動物的照顧和野放。
  - Sqoyaw 8 個地標打卡。
- **老師模式**：
  - 改題目、公告、倒數看板、海玻璃單字、Google 表單連結。
  - 看全班進度、補發印章和金幣、重設進度。
  - 設定班級密碼和老師密碼，設定全班天色（白天／傍晚／夜晚／跟著真實時間）。
  - 只有老師能用任意門。
- **雲端**：存檔、即時看到同學、遊玩時間提醒。
- **畫面**：
  - 照美術初稿 v0.2 改色。
  - 遠山換成手繪環景；Sqoyaw 屋頂、牆面換新貼圖；夜晚調亮；69 支路燈。
  - 學校一帶的 3D 樣板：手繪明暗、手繪葉團樹。
  - 省電模式。
- **操作**：直式和橫式都可以玩；滑鼠拖曳只轉鏡頭。

## 8. 已知問題

1. **亮度不一致**：3D 和 2D 手繪場景的亮度、顏色不一樣，夜晚也曾經全黑（已調亮）。推測原因和下一步請看 `CLAUDE.md` 第 6 節 A。**還沒在真手機上確認。**
2. **穿模和「漏畫」**：
   - 站在 Sqoyaw 高樓牆邊時，鏡頭會拉近到背後。
   - Sqoyaw 為了不讓鏡頭卡進房子，開了「穿透視角」，鏡頭和人物之間的房子會被挖空。
   - 使用者說的「漏畫」是哪一種還沒確認。
3. **房間人物比例**：每個 2D 房間要用門和桌椅的高度逐間校正人物大小，不能全部直接放大一倍。
4. **遠山清晰度**：還沒在手機上確認。
5. **素材大小**：repo 接近 GitHub Pages 1 GB 的上限。
